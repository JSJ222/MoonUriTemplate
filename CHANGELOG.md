# Changelog

## 0.3.0 — 2026-10-22

- Reposition around a separate `contracts` package for offline API contract workspaces; retain root URI API compatibility.
- Add bounded OpenAPI 3.1 JSON import and decoded request/response validation using moonschema 0.2.0.
- Add explicit cross-document schema locks, transitive reverse dependencies, immutable atomic updates and affected-operation rebuilding.
- Add conservative breaking/review/additive reports, baseline-checked consumer upgrade gates, positive coverage and targeted candidate replay; export JSON evidence.
- Add three asserted scenarios, public-interface safety/regression tests, 351 independent python-jsonschema comparisons and 200/1000-operation cold-equivalence workloads.
- Document exact support limits, serial access, numeric domain, whole-lock copy costs and no universal compatibility/performance guarantees.

- Add public API regressions and asserted SDK/MCP examples; document complexity and limits.
- Close mutable-field exposure in Template, TemplateCatalog and BoundTemplate; direct-field consumers must use their existing public methods.
