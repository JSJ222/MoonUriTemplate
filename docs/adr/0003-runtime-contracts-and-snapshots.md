# Add opt-in contracts and immutable incremental link snapshots

Runtime shape/presence contracts serve SDK requirements without changing RFC
omission. Rules are validated against the compiled template and captured apart
from caller arrays. They are not a schema language or URI destination policy.

Catalog sessions track shared bindings and variable dependencies. Atomic updates
return new snapshots and actual URI changes in catalog order; failures cannot
replace valid old snapshots. Composite inputs and returned arrays are copied.
Private immutable indexes/maps can be shared. Whole-snapshot budgets are
measured before rendering affected endpoints.

This extends forward expansion and agrees with ADR 0001. It introduces no
router, HTTP client or resolver. Full expansion remains preferable for unrelated
request rows or when most links change.
